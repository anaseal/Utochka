# Silyanka

Параметрический SVG-редактор для силянки (плетёных бисерных украшений). Симулирует физическую геометрию плетения вместо пиксельной сетки.

## Команды

- `npm run dev` — запуск dev-сервера
- `npm run build` — `typecheck && vite build`
- `npm run typecheck` — проверка типов (`tsc --noEmit`, `strict: true`)
- `npm run lint` — ESLint (`.ts/.tsx`)
- `npm test` — тесты (Vitest, one-shot)
- `npm run test:watch` — тесты в watch-режиме
